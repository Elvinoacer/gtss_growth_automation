Security & Data

Passphrase management and the irreversible "clear all data" control.

Change Passphrase

Your passphrase encrypts platform sessions and API keys at rest. Choose a strong one — at least 12 characters.

Clear All Data

This will permanently delete all leads, messages, and history. Cannot be undone.

Storage Cleanup

Nightly crons clean debug artifacts (3:30 AM) and orphan top-level uploads (3:00 AM). Run the same jobs immediately here. Library assets under uploads/library/ are never touched.
